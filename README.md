# Build to Own — salepage

Trang bán hàng tĩnh cho chương trình **Build to Own**, nội dung tiếng Việt và CTA đăng ký qua Luma.

## Xem tại máy

Mở `salepage.html` bằng trình duyệt hoặc dùng một máy chủ tĩnh tại thư mục này.

## Build

```bash
npm run build
```

Thư mục triển khai được tạo tại `dist/`.

## Triển khai

Cấu hình Vercel nằm trong `vercel.json`. Mỗi lần đẩy nhánh `main`, có thể triển khai lại từ repository hoặc bằng Vercel CLI.
